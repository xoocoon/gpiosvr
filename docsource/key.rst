Core concepts
-------------

.. _key-press:

Key press
^^^^^^^^^

A key press is a series of events starting when a key is held down and ending
when the key is released again. 

In between, the key may be repeated periodically. The repeat interval depends on
the hardware setup and kernel parameters in the case of a physical keyboard,
remote control etc. In the case of artificial key presses generated by the
:mod:`~.signal_button` module, the interval can be set with
:paramref:`~.signal_button.ButtonIterator.repeat_ms`.

Short and long key press
^^^^^^^^^^^^^^^^^^^^^^^^

Whether a key press is considered "short" or "long" depends on the value of 
:attr:`~.KeyHandlingConfigs.longPressRepeatCount`.

* A short press has less than `longPressRepeatCount` repeat events.
* A long press has exactly or more than `longPressRepeatCount` repeat events.

.. _key-alternate:

Alternate mode
^^^^^^^^^^^^^^

The handling configuration for a key may specify an alternate handling 
configuration via :attr:`~.KeyHandlingConfig.altConfig`. It replaces the
original handling configuration when the alternate mode is on.

The alternate mode is toggled via :meth:`~.KeyServer.toggleAltMode`. Toggling is
also possible via a handling configuration with an 
:attr:`~.KeyHandlingConfig.alias` value set to one of the members or member
names of :class:`~.AltAlias`.

The state of the alternate mode can be checked via
:attr:`~.KeyServer.isAltModeOn`.

Note that the :mod:`~.input` module also features an alternate mode. The latter
works at the input level, i.e. alternate input events are reported to the Linux 
kernel in the first place.

.. key-configuration:

Configuration classes
---------------------

The following is the JSON representation of an exemplary collection of key
handling configurations:

.. code-block:: none

  {
    "longPressRepeatCount": 8,
    "KEY_VOLUMEDOWN": {
      "shortPressCommands": [
        [
          "/usr/bin/curl",
          "-s",
          "http://multiroom-1/stepVolume?step=-1"
        ]
      ],
      "longPressCommands": [
        [
          "/usr/bin/curl",
          "-s",
          "http://multiroom-1/setMute?enable=true"
        ]
      ],
      "ledColor": "magenta",
      "isRepeatable": true,
      "altConfig": "KEY_F9"
    },
    "KEY_VOLUMEUP": {
      "shortPressCommands": [
        [
          "/usr/bin/curl",
          "-s",
          "http://multiroom-1/stepVolume?step=1"
        ]
      ],
      "ledColor": "magenta",
      "isRepeatable": true,
      "altConfig": "KEY_F10"
    }
  }
