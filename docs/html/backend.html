A collection of information about a GPIO backend.

__init__(type, gpioApi)

Creates an info collection about a GPIO backend.

Parameters:

gpioApi¶ – The GPIO API to determine the version identifier of the backend. If None, version is also None in most of the cases.

type: BackendType

The type of the GPIO backend.

version

The version identifier of the GPIO backend.

class gpiosvr.backend.BackendType(value)

The type of GPIO backend to be used on the server side.

GPIOD = 'gpiod'

The gpiod Python bindings for the libgpio C API, accessing a built-in GPIO chip of the Linux host.

PICOSSA = 'picossa'

The gpiosvr.picossa module, connected to a Raspberry Pico board or another RP2040- or RP2350-based microcontroller.

PIGPIOD = 'pigpiod'

A running pigpio Daemon, accessing a built-in GPIO chip of the Linux host.
