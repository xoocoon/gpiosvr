address

A constant value identifying the vendor or protocol variant. For example, in the RC6 protocol, the address 0x800f stands for the Microsoft (MCE) variant.

addressBitCount: int

The number of bits reserved for the address. Also see address.

codeBitCount: int

The number of bits reserved for the scan code of a remote control button.

hasCheckBits: bool

If True, the IR protocol includes a 1:1 or inverted copy of all the address and code bits.

async pulseEventToInputEvents(pulseEventOrKeyCode, debugOutput=None)

Decodes a pulse event to input events.

May be overridden for extensibility.

Parameters:

  • pulseEventOrKeyCodes¶ (PulseEvent | PulsesInterrupted | list | tuple) – Either a pulse event to decode or, as a short cut, a sequence of codes if they are already known. Codes must start with 0x.

  • debugOutput¶ (io.StringIO | None) – A string buffer for appending debug messages. Defaults to None.

Returns:

A sequence of input events carrying the codes decoded from the pulse event. If pulseEventOrKeyCodes is a sequence of codes, they are used directly.
