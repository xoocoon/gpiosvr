Configuration classes

The classes in this section evaluate and hold configurations for UART transmission (TX) and receiving (RX). They can be initialized with dict instances, e.g. read from JSON files.

Auto-discovering and parsing JSON files are out of scope for gpiosvr.uart. See the ctlbase.config module instead. The following is the JSON representation of an exemplary UART configuration:

"uart0": {
  "baud": 9600,
  "isCloseOnExit": false,
  "pauseBeforeReading_ms": 200,
  "readBufferBytes": 64,
  "readTimeout_ms": 2000,
  "readDelimiter": "0x0A",
  "readDelimiterMinCount": 1,
  "keys": {
    "BELL": {
      "keyName": "KEY_SOUND"
    }
  }
}
class gpiosvr.uart.UartParameters(channel, baud, dataBitCount=None, stopBitCount=None, parity=None, isCloseOnExit=None, pauseBeforeReading_ms=None, readTimeout_ms=None, readBufferBytes=None, readDelimiter=None, readDelimiterMinCount=None)

A collection of technical parameters for a UART channel.

__init__(channel, baud, dataBitCount=None, stopBitCount=None, parity=None, isCloseOnExit=None, pauseBeforeReading_ms=None, readTimeout_ms=None, readBufferBytes=None, readDelimiter=None, readDelimiterMinCount=None)

Creates a collection of technical parameters for a UARt channel.

Parameters:

  • channel¶ (int) – The UART channel for which the parameters are valid. It must be 0 or 1.

  • baud¶ (int) – The baud rate of the UART connection.

  • dataBitCount¶ (int) – The number of data bits for the UART connection. Defaults to 8.

  • stopBitCount¶ (int) – The number of stop bits for the UART connection. Defaults to 1.

  • parity¶ (int) – The parity type for the UART connection. See Uart for accepted values. Defaults to PARITY_NONE.

  • isCloseOnExit¶ (bool) – If True, the UART connection is closed as soon as the process terminates. If False, the UART connection survives the process that initiated the connection. Defaults to True.

  • pauseBeforeReading_ms¶ (int) – The pause in milliseconds to be taken after a command is sent via the UART channel. Bytes are only read in response after that pause. Defaults to the value of PAUSE_BEFORE_READING_DEFAULT_MS.

  • readTimeout_ms¶ (int) – The maximum time span in milliseconds to wait for bytes to read. Defaults to the value of READ_TIMEOUT_DEFAULT_MS.

  • readBufferBytes¶ (int) – The maximum number of bytes to read in one go. Defaults to the value of READ_BUFFER_BYTES_DEFAULT.

  • readDelimiter¶ (str | bytes | bytearray) – The byte sequence serving as a delimiter. If it is a str prefixed with 0x, it is interpreted as a hexadecimal value. Any other str is interpreted as plain ASCII. Defaults to the value of READ_DELIMITER_DEFAULT.

  • readDelimiterMinCount¶ (int) – The minimum number of occurrences of the delimiter. That is, if the delimiter is encountered that many times in the byte sequence read so far, receiving stops and any surplus bytes are discarded. Defaults to the value of READ_DELIMITER_MIN_COUNT_DEFAULT.

Raises:

ValueError – If a value in the configuration is outside the allowed range.

class gpiosvr.uart.UartConfig(uartConfig: dict)

Properties describing a compound configuration for sending and receiving data via UART.

They combine the technical parameters for a UART channel (UartParameters) and key handling configurations (KeysConfig).

__init__(uartConfig: dict)
Parameters:

uartConfig¶ (dict) –

Under evdevName (str), the dict may specify a logical name (str) for the device to which key events are published. This is not the name of a device under /dev/input/. It is an arbitrary name to be passed to the gpiosvr.bin.key_monitor executable.

Under uart0 and/or uart1 (str), the dict must specify the technical parameters (UartParameters) for the respective UART channel.
Next to the technical parameters, the dict may specify a collection of key handling configurations (KeysConfig) under keys (str). They determine how to proceed with data read from the respective UART channel.

Raises:

ValueError – If a value in the configuration is outside the allowed range.
